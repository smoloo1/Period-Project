# Period Pain Hub

A science-backed, easy-to-understand website that helps people understand why period pain happens, recognize what kind of pain they have, and find solutions that actually fit—without fear mongering or medical jargon.

## About This Project

Period Pain Hub is an educational resource designed to:
- **Validate pain without normalizing suffering**: Acknowledge that period pain is real while emphasizing that severe pain deserves attention
- **Provide science-backed information**: All content is based on current medical evidence and research
- **Use accessible language**: No medical jargon, clear explanations, and user-friendly terminology
- **Empower decision-making**: Help users understand their options and when to seek professional care
- **Support individual experiences**: Recognize that pain manifests differently for everyone

## Features

### 1. Understanding Period Pain
Educational content explaining:
- Why period pain occurs (prostaglandins and uterine contractions)
- Primary vs. secondary dysmenorrhea
- What's considered normal vs. when to seek care

### 2. Interactive Pain Profile Assessment
Users can:
- Select their pain types (cramping, sharp, aching, radiating, bloating, digestive)
- Indicate pain severity (mild, moderate, severe)
- Receive personalized recommendations based on their profile

### 3. Evidence-Based Solutions
Solutions organized by mechanism and category:
- **Heat & Cold**: Heat therapy and its effects on muscle relaxation
- **Movement**: Exercise, yoga, and pelvic floor relaxation
- **Dietary**: Anti-inflammatory foods, magnesium, and hydration
- **Medical**: NSAIDs, hormonal birth control
- **Mind-Body**: Relaxation techniques, meditation, TENS

Each solution includes:
- Evidence level (Strong/Moderate)
- How it works (mechanism of action)
- Practical implementation tips

### 4. Red Flags & When to Seek Care
Clear guidance on:
- Symptoms requiring immediate attention
- When to schedule a healthcare appointment
- How to prepare for medical visits
- Advocacy tips for patient self-representation

## Getting Started

### Quick Start
Simply open `index.html` in any modern web browser. No build process or dependencies required.

### Local Development
1. Clone the repository:
   ```bash
   git clone https://github.com/smoloo1/Period-Project.git
   cd Period-Project
   ```

2. Open in browser:
   ```bash
   # On macOS
   open index.html
   
   # On Linux
   xdg-open index.html
   
   # Or simply double-click index.html
   ```

3. For live reloading during development, you can use a simple HTTP server:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Python 2
   python -m SimpleHTTPServer 8000
   
   # Node.js (if you have http-server installed)
   npx http-server
   ```
   Then visit `http://localhost:8000`

## Key Design Principles

1. **Accessibility First**: 
   - Semantic HTML structure
   - ARIA labels where appropriate
   - Keyboard navigation support
   - Skip-to-content link
   - High color contrast

2. **Mobile Responsive**:
   - Flexible grid layouts
   - Touch-friendly interface
   - Readable typography on all screen sizes

3. **Evidence-Based Content**:
   - Clear labeling of evidence strength
   - Mechanisms explained without jargon
   - Balanced presentation of options

4. **User-Centered**:
   - Pain profiles based on symptom experience
   - Personalized recommendations
   - Decision support without overwhelming
